# NetHack SDL3

A lightweight fork of NetHack 5.0-dev with an SDL3 host platform: the
classic `win/curses` interface (persistent inventory, menus, status
highlighting) rendered into an SDL3 window with a square bitmap font
and a pastel palette on dark slate.  It feels like a terminal without
being one: resizable, hidpi-aware, and self-contained.

## Building

Prerequisites: a C/C++ compiler (tested with w64devkit gcc on Windows)
and CMake ≥ 3.28.  Everything else — SDL3, Lua 5.4.8, PDCursesMod —
is downloaded by CMake over HTTPS and verified against pinned SHA256
hashes.

```
cmake -S sys/sdl3 -B build
cmake --build build -j
```

The result is a single self-contained `build/nethack.exe`: the game
data archive (`nhdat`) is embedded in the executable.

On Linux, SDL3 additionally wants the usual X11/Wayland development
headers installed to produce a usable video backend.

## Options

| CMake option | default | meaning |
|---|---|---|
| `NETHACK_UI` | `sdl3` | curses backend: `sdl3`, or PDCursesMod's `wincon`/`vt` (debug bring-up) |
| `NETHACK_SDL3_PORTABLE` | `ON` on Windows | all runtime files (saves, scores, config) live next to the exe; `OFF` = `SDL_GetPrefPath` (`%AppData%\NetHack\NetHack-SDL3\`, `~/.local/share/NetHack/NetHack-SDL3/`) |
| `NETHACK_SDL3_CONSOLE` | `ON` | Windows console subsystem (early errors visible); `OFF` = pure GUI app |

## Packaging

```
cpack --config build/CPackConfig.cmake -B build
```

produces `nethack-sdl3-<version>-win-<arch>.zip` containing the
executable, `LICENSES.txt` (NetHack + SDL3 + Lua + component notes,
generated at configure time), and `Guidebook.txt`.  Running `cpack`
directly does not rebuild, so post-build steps applied to
`build/nethack.exe` (stripping, signing) survive into the package.

## Runtime files

On first launch the game seeds `sysconf`, `.nethackrc`, and `symbols`
into its data directory.  The default `.nethackrc` sets up the
intended look: bordered windows, map on top, tall message pane below,
3-line status, persistent inventory on the right, menucolors.  Edit
it freely; delete it to get a fresh copy.

Closing the window acts like a hangup: the game saves and exits
(press the close button twice to force-quit).

## Architecture

- `sys/sdl3/CMakeLists.txt` — the entire build: host tools
  (`makedefs`, `dlb`, `bin2c`, `hex2c`), Lua, PDCursesMod core + our
  backend, data generation staged under the build dir, the game.
- `sys/sdl3/pdcsdl3/` — an SDL3 platform backend for PDCursesMod
  (the standard 7-file contract, modeled on their `sdl2/` backend),
  rendering cells from an embedded [unscii-8](http://viznut.fi/unscii/)
  8×8 font (public domain) at an integer scale.
- `sys/sdl3/sdl3main.c`, `sdl3sys.c` — the host platform: `main()`,
  path handling via `SDL_GetBasePath`/`SDL_GetPrefPath`, locking,
  OS hooks.  All ten `fqn_prefix[]` slots point at one directory.
- `include/sdl3conf.h` — config deltas layered on `windconf.h` /
  `unixconf.h` (the native `WIN32`/`UNIX` macros stay in effect).
- `DLBMEM` (in `include/dlb.h` + `src/dlb.c`) — a dlb provider that
  serves the game data from a C array generated by `bin2c` from the
  packed `nhdat`.  Loose files beside the exe still override embedded
  ones (dlb's normal fallback), handy for data hacking.

Upstream files are otherwise untouched; `win/curses` runs unmodified.
